# A-Hybrid-Non-Uniformity-Correction-Method-
Project Overview
This repository is associated with the research paper entitled "A Hybrid Non-Uniformity Correction Method for Uncooled Multispectral Infrared Cameras Based on an Embedded Reflective Reference Source", which focuses on the non-uniformity correction technology for uncooled multispectral infrared cameras.
Code and Data Release Notice
The source code and experimental data corresponding to this paper involve internal technical parameters and experimental raw data that need to undergo declassification and desensitization processing in accordance with the data security regulations of the research institution.
Key Notes:
The declassification process is currently in progress, and we will complete the screening, anonymization, and standardization of the code and data to ensure compliance with relevant regulations while retaining the core reproducibility of the research results.
After the declassification processing is completed, all relevant code and processed experimental data will be uploaded to this repository. The release content will include:
Source code of the hybrid non-uniformity correction algorithm
Processed experimental datasets (with sensitive parameters removed)
Detailed instructions for code running and result reproduction
